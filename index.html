Kenapa statis + Cloudflare Pages?

WordPress asli butuh PHP + MySQL sehingga tidak bisa jalan murni di Workers & Pages. Template ini adalah versi statis (gaya WordPress) yang bisa di-host gratis di Cloudflare Pages dan dihubungkan ke bloginsurance.my.id. Kalau butuh editor WordPress, jalankan WordPress lokal via Docker, lalu export ke statis. Lihat INSTRUKSI-CLOUDFLARE.md.
