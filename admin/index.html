Admin Blog (Git-based)

100% statis, cocok untuk Cloudflare Pages. Token GitHub hanya disimpan di browser kamu (localStorage), tidak pernah masuk ke repo. Buat token baru di GitHub → Settings → Developer settings → Personal access tokens → Fine-grained: pilih repo dalamnegri/wp, izin Contents: Read and write. Jangan pakai token lama yang bocor.

Cara kerja: admin membuat file content/posts/<slug>.md + update content/index.json via GitHub Contents API. Cloudflare Pages yang tersambung via Connect to Git akan deploy otomatis 1–2 menit. Baca di /blog/post.html?p=<slug>.
